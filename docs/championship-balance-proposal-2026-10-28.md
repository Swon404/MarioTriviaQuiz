# Championship balance — approved rule

Status: approved 29 October 2026; implemented and fully verified 30 October. Dad also
requested one Clue Match Up board per player in Championship. Standalone matching
keeps two boards. Existing saves and historical scores retain their prior rules.

## Approved rule

Keep each game's current scoring and determine its winner as today. Then award
**one Championship point for winning that game**, zero for losing, and **one each
for a drawn game**. The player with more Championship points wins the Championship.
Equal Championship points mean a draw: no hidden time or raw-score tiebreaker.

This gives each selected game the same maximum influence on the final margin:
one point. A drawn game adds one to both players and changes neither player's lead.
There are no fractions, multipliers, speed bonuses or changes to board sizes.

| Quick Rookie example | Blaize's game score | Dad's game score | Championship points |
| --- | ---: | ---: | --- |
| Quiz Battle | 2 | 3 | Blaize 0, Dad 1 |
| Clue Match Up (one board) | 4 | 0 | Blaize 1, Dad 0 |
| Total | 6 | 3 | **1–1 draw** |

Under action-point totals Blaize wins that example 6–3.
With the approved rule each won one game, so the Championship is drawn. Winning a game
by a large margin no longer outweighs winning a different game narrowly.

## Screen meanings

- During a game: **This game: 2–1** and **Championship: 1–0**, with clear column labels.
- At the end: **Blaize wins Quiz Battle, 3–2. +1 Championship point.**
- Draw: **Game drawn, 2–2. +1 Championship point each.**
- Final result: **Blaize wins the Championship, 3–2.** A per-game table explains it.
- Setup: **Each game win earns 1 Championship point. A drawn game earns 1 each.**

Timed games still compare their rounds first: three in Hunt, and three/four/five
in Game Order by Championship length. Their existing individual round awards
determine the game winner. Untimed Hunt still uses the shared board.
Shroomer follows exactly the same calculation. Solo Championship keeps action
points because there is no opponent or game winner to compare.

## Progress and compatibility

Action points continue to feed lifetime learning progress; Championship points
are a separate result tally, not extra currency. Never add both to lifetime totals.
Old Championship records and already-started runs keep their old rules. New balanced
records get an explicit rules version and separate comparable score groups. Export,
import, reload and the results table must preserve that version.
